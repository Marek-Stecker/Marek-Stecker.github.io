Projects

Training App - MyWayWall

A mobile app designed for a customizable climbing training. It requires the ownership of a custom climbing wall (currently sold only in CR), that has transparent holds with LEDs behind them. This gives the user almost infinite possibilities for the routes to create.

Features:

  • Connect to the led wall (ESP32) using Bluetooth.
  • Create and edit routes - select difficulty, wall angle, and choose positions for the holds.
  • Train on routes - simply select the route by name or filter by difficulty and angle.
  • Create a custom training plan - set up a timer and select holds you want to train on.
  • Share the routes with friends - simply copy a piece of "code" and your friend paste it in.

Availability: Android, iOS
Built with: Unity, C#, Arduino IDE

Horror Game - Light Bearer

A 2D horror game with light tranforming mechanics. You are a lightkeeper in a lighthouse and need to bring the light back. Use you magical tool to move the light from one light source to another. Fight the mosters of the darkness and stay sane!

Gameplay features:

  • Light tool - ability to capture light and move it.
  • Inventory management - use cart to move resources and fuel.
  • Sanity - stay in well-lit areas to avoid getting insane.
  • Puzzles - complete puzzles to gain access to new areas.
  • Random map generation - every run is different.

Availability: PC (not yet)
Built with: Unity, C#, Aseprite

Web Quiz - Will It Compile?

Programming quiz where players decide if code compiles or has errors. This can be a fun way to improve in debugging and understanding someone else's code. It is also a good way to test your skills and compare yourself with your friends.

Features:
