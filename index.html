Projects

Training App - MyWayWall

A mobile app designed for customizable climbing training. It requires a custom climbing wall (currently sold only in the Czech Republic) with transparent holds and LEDs behind them. This setup provides users with almost unlimited possibilities for creating routes.

Features:

  • Connect to the LED wall (ESP32) via Bluetooth.
  • Create and edit routes - select difficulty, wall angle, and hold positions.
  • Train on routes - select the route by name or filter by difficulty and angle.
  • Create custom training plans - create sets, set duration and holds.
  • Share routes with friends - copy a code that others can paste into the app.

Availability: Android, iOS
Built with: Unity, C#, Arduino IDE

Horror Game - Light Bearer

A 2D horror game with light tranforming mechanics. You play as a lighthouse keeper who must restore the light. Use your magical tool to transfer light between sources, fight mosters lurking in the darkness and maintain your sanity.

Gameplay features:

  • Light tool - capture and transfer light.
  • Inventory management - use a cart to transport resources and fuel.
  • Sanity - stay in well-lit areas to avoid losing sanity.
  • Puzzles - solve puzzles to unlock new areas.
  • Procedural level generation - each run is different.

Availability: PC (not yet)
Built with: Unity, C#, Aseprite

Web Quiz - Will It Compile?

Programming quiz where players decide if code compiles or has errors. This can be a fun way to improve in debugging and understanding someone else's code. It is also a good way to test your skills and compare yourself with your friends.

Features:

DAGDC's Winter 2026 Game Jam

  • Theme: XOXO
  • Duration: 7 days

In Tic-Tac-Shift you play tic-tac-toe on a 4x4 grid with the main difference that you can shift the board after placing the symbols. So if you get into a tie, just move a column or row to your advantage. You may also find coins which you need to connect with your symbols to get them and then you can buy more abilities in the shop.
