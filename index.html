Projects

Training App - MyWayWall

A mobile app designed for climbers, providing a new and customizable way of training. It requires a custom climbing wall (currently sold only in the Czech Republic) with transparent holds and LEDs behind them. This setup provides users with almost unlimited possibilities for creating routes.

Features:

  • Connect to the LED wall (ESP32) via Bluetooth.
  • Create and edit routes - select difficulty, wall angle, and hold positions.
  • Train on routes - select the route by name or filter by difficulty and angle.
  • Create custom training plans - create sets, specify duration and holds for training.
  • Share routes with friends - copy a code that others can paste into the app.

Availability: Android, iOS
Built with: Unity, C#, Arduino IDE

Horror Game - Light Bearer

A 2D horror game with light-transforming mechanics. You play as a lighthouse keeper who must restore the light. Use your magical tool to transfer light between sources, fight monsters lurking in the darkness and maintain your sanity.

Gameplay features:

  • Light tool - capture and transfer light.
  • Inventory management - use a cart to transport resources and fuel.
  • Sanity - stay in well-lit areas to avoid losing sanity.
  • Puzzles - solve puzzles to unlock new areas.
  • Procedural level generation - each run is different.

Availability: PC (not yet)
Built with: Unity, C#, Aseprite

Web Quiz - Will It Compile?

A programming quiz where players decide whether code compiles or not. It's a fun way to improve debugging skills and better understand other developers' code. It also allows players to test their skills and compare results with friends.

Features:

  • Randomly selected questions.
  • Daily quiz - a set of 5 questions.
  • Leaderboard - tracks username, score and completion time.

Availability: Web
Built with: HTML, CSS, JS, Node.js
